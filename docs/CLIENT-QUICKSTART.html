Whale Dive Centre — Quickstart Admin (1 halaman)

Login

  • Admin site: /wp-admin/
  • Member: /login/
  • Jangan pakai akun admin untuk testing member biasa.

Edit konten site

Menu WDC Site
- Contact & Footer
- Home Content
- Notifications
- About Page
- Contact Page
- Partners / Trust
- Crew Profiles
- Testimonials

Edit kursus / gear

  • Dive Courses → harga, deskripsi, featured image, CTA
  • Dive Equipment → harga, stok, size, featured image, CTA

Foto = Featured image di post itu.

Request member

  1. Member login di /login/
  2. Ajukan dari dashboard / my-courses / my-gear
  3. Crew dapat email (atur di WDC Site → Notifications)
  4. Follow-up manual

Cerita Kamu

  1. Member submit → Pending
  2. Admin buka menu Cerita Kamu
  3. Approve & publish
  4. Baru tampil di Blog

Jangan diubah

Theme code, plugin teknis, permalink, server, DNS.

Cek cepat setelah edit

  • Hard refresh browser
  • Cek HP: Home, 1 course, 1 gear
  • Pastikan harga tampil, tombol daftar/beli minta login
